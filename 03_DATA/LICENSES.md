# Data licences and redistribution

1. **Kyrgyz regional crop yield.** The Open Data Kyrgyzstan metadata page labels the dataset Creative Commons Attribution. The original XLS and the converted XLSX are included in the submission reproducibility package with attribution and unchanged values. Redistribution status: permitted with attribution according to the displayed licence; users should re-check the portal before onward redistribution.

2. **Annual temperature anomalies.** Our World in Data states that its own data, visualizations and code are CC BY, while third-party source data remain subject to the source provider's terms. The extracted series is published here with full attribution to modified Copernicus Climate Change Service information and OWID processing. Downstream users must preserve attribution and review current Copernicus terms.

3. **Code.** Original analysis code in the submission reproducibility package is released under the MIT License.
